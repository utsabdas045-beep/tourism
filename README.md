🌄 Explore Tripura – Travel Destination Website
📌 Project Overview

Explore Tripura is a responsive travel destination website developed using HTML5 and CSS3.
The project showcases the natural beauty, cultural heritage, and major tourist attractions of Tripura, a northeastern state of India, through a clean and user-friendly interface.

📝 Project Description

Explore Tripura is designed to promote tourism by presenting key information about the state’s history, culture, and popular destinations. The website uses modern CSS layout techniques, animations, and dark mode to enhance user experience while remaining lightweight and JavaScript-free.

🛠️ Technologies Used

HTML5

CSS3

CSS Flexbox & Grid

Media Queries (Responsive Design)

✨ Features

Responsive layout (mobile, tablet, desktop)

CSS-only dark mode toggle

Smooth animations and hover effects

Multi-page structure (Home, About, Places)

Clean and modern UI design

Lightweight and fast-loading
